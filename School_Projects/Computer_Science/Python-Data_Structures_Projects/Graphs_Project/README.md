# Graph Algorithms: Connected Components & Bipartite Check

This project implements two fundamental graph algorithms:

1. **Connected Components** using Depth-First Search  
2. **Bipartite (2-color) Testing** using Breadth-First Search  

Graphs are stored using custom Graph and Vertex classes — with queues and
stacks implemented from scratch.

---

## Concepts Demonstrated

- Graph representation
- Depth-First Search (DFS)
- Breadth-First Search (BFS)
- Connected components
- Bipartite / 2-coloring
- Cycle detection intuition
- Test-driven development
