# Steam Review Dip Analysis

**Technologies:** Python, Jupyter Notebook, EDA, large-scale data processing

Project analyzing whether “review dip periods” (sharp spikes in negative Steam reviews) differ from normal review periods for video games. The goal is to see if negative-review spikes reflect different user behavior (e.g., highly engaged players reacting to developer decisions) compared to baseline review activity.

**Dataset:** 100 Million + Steam Reviews (from Kaggle)

**Repository:**  
https://github.com/OwenLoughery/Steam_Review_Dips_Analysis

**Key files:** `EDA.md`, `Report.md`, `preprocess.py`
