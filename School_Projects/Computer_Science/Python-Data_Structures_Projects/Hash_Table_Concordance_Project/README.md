# Hash Table & Concordance Builder

This project implements:

1. A custom Hash Table using **open addressing + quadratic probing**  
2. A Concordance program that builds an alphabetical index of words and the
   line numbers where they appear

All data structures and algorithms were implemented from scratch — no Python
dictionary or built-in maps were used.


---

## Testing

Full unit test coverage including:

- insertion
- lookup
- probing collisions
- table resizing
- concordance generation
- stop-word filtering
- edge cases (empty files, punctuation, duplicates)
