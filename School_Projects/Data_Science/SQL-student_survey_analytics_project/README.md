## Student Survey Analytics (SQL + Data Visualization)

**Technologies:** SQL Server (Azure), SQL Stored Procedures, C#, ASP.NET Core MVC  

A data-driven web application that analyzes anonymized student survey data using SQL stored procedures and presents insights through clear visualizations. The project focuses on querying cloud-hosted data, aggregating survey responses, and communicating trends related to stress, workload, and career outlook.
