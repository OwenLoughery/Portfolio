# Java Virtual World Simulation

This project is a multi-phase Java simulation I built across a whole quarter for my CSC object-oriented programming class.  
I refactored a large codebase, implemented A* pathfinding, added new entities, and created interactive world events.

**Full project repository:**
https://github.com/OwenLoughery/java-world_simulation_project

### Highlights
- Refactored “God class” structure into clean OOP hierarchy
- Designed UML class diagrams
- Implemented A* pathfinding with Strategy Pattern
- Built new animated entities with custom behavior
- Added interactive world events triggered by mouse clicks
- Maintained working unit tests through refactors
