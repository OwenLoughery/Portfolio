# r/place 2022 Canvas Analytics (CSC 369)

**Technologies:** Python, DuckDB/SQL, data preprocessing, exploratory analysis, Random Forest, SHAP

A set of course tasks for **CSC 369** using the **r/place 2022** dataset. The work includes:
- Preprocessing a large raw dataset into a smaller analysis-ready format
- Baseline behavioral summaries (color usage, sessions, first-time users)
- An irregular activity investigation grouped into "buckets" (pixel warfare, task-specialized automation signals, onboarding spikes)
- A machine learning model that predicts whether a pixel placement will **survive ≥ 30 minutes**, plus SHAP interpretation and interactive plots
